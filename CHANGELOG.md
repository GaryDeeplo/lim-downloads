# Changelog

## 1.0.0 (2026-11-13)

First public version.

- Batches: exact duplicates, extracted zips, old installers, already backed up, partial downloads, re-downloadable files, sorting by type.
- 30-day quarantine visible in the app: restore one file or a whole batch, delete a batch, empty everything.
- History with undo, CSV receipts of everything quarantined.
- Optional auto-sort (off by default) with its own panel: delay, allowed actions, waiting files.
- Lim, the robot guide, for the first launch.
- Own window (WebView2), tray icon, Windows notifications, start with Windows.
- Local API restricted to the app itself.
