# Lim — interface

React + TypeScript + Vite front end of Lim, served by the Python app from `dm/static`.

- `npm ci` then `npm run dev` while working on the interface (the Python server must run on port 8765).
- `npm run build` type-checks and writes the production build to `../dm/static` (commit it with your change).
- Translations: French text is the key, English lives in `src/i18n/*.ts`.

See the main [README](../README.md) and [CONTRIBUTING](../CONTRIBUTING.md).
